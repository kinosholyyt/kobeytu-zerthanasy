# Көбейту зертханасы

- 6 ойын, әрқайсында 3 деңгей (A — базалық, B — орта, C — жоғары)
- AI-саралау: оқушының жауабына қарай деңгей өзі ауысады
- Соңында мұғалімге арналған саралау есебі

Оқу мақсаттары: 2.1.2.4, 2.1.1.5.
